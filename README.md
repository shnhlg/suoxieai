# SuoxieAI 缩写数据集

本仓库仅提供 SuoxieAI 缩写数据样本，不包含网站源码、服务端程序、部署文件或内部实现。

## 数据样本

公开文件为 `data/suoxieai_sample.jsonl`，包含完整词库中确定性抽取的 10% 样本，共 65,222 条记录。

每行是一个 JSON 对象，并且只有两个字段：

```json
{"abbr":"xswl","meanings":["笑死我了"]}
```

- `abbr`：缩写。
- `meanings`：该缩写对应的释义数组。

## 在线使用

访问 [suoxieai.paulkoishi.com](https://suoxieai.paulkoishi.com/) 使用完整的在线缩写查询服务。

网站支持：

- 按缩写或释义快速搜索，并分页浏览查询结果。
- 使用普通搜索或标签搜索查找词条。
- 区分较明确的释义与“有可能是”的候选释义。
- 点击释义后使用百度、Bing、Google、Yandex 或自定义搜索引擎继续检索。
- 对缺失或难以直接匹配的缩写使用 AI 猜测，给出可能的完整表达；猜测结果仅供参考。
- 在桌面端和移动端浏览与查询。
